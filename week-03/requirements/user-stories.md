# User stories — Smart Campus study room booking

### US-01
**Story:** As a Student, I want to view available study rooms, so that I can choose a room that fits my needs.
**Priority:** High
**Assumption:** The system contains an up-to-date list of study rooms and their availability slots.

### US-02
**Story:** As a Student, I want to book an available study room for a specific time, so that I can reserve a place to study.
**Priority:** High
**Assumption:** Students can make bookings only for available and future time slots.

### US-03
**Story:** As a Student, I want to view my current and upcoming bookings, so that I can keep track of my reserved rooms.
**Priority:** Medium
**Assumption:** The system stores and displays each student's active bookings.

### US-04
**Story:** As a Student, I want to cancel my booking, so that I can release the room when I no longer need it.
**Priority:** Medium
**Assumption:** Students are allowed to cancel only their own bookings prior to the start time.

### US-05
**Story:** As an Administrator, I want to block or unblock a study room for a specific time, so that the room cannot be booked when unavailable.
**Priority:** High
**Assumption:** Administrators have permission to override room availability statuses.

### US-06
**Story:** As an Administrator, I want to view all study room bookings and usage reports, so that I can monitor room usage on campus.
**Priority:** High
**Assumption:** Administrators can access complete booking histories and current usage metrics.
